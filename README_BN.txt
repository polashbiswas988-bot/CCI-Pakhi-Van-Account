CCI পাখি ভ্যান ম্যানেজমেন্ট — প্রস্তুত প্রাথমিক সংস্করণ

ফাইল:
- index.html: অ্যাপ
- manifest.json: ফোনে ইনস্টল করার তথ্য
- sw.js: অফলাইন ক্যাশিং
- README_BN.txt: এই নির্দেশিকা

সুবিধা:
- ভ্যানের তথ্য: নম্বর, মডেল, কেনার তারিখ, ক্রয়মূল্য, অবস্থা, দৈনিক ভাড়া, বর্তমান চালক।
- চালক/প্যাডলারের তথ্য: আইডি, নাম, ফোন, ঠিকানা, ভ্যান, দৈনিক ভাড়া, ছবি।
- দৈনিক আদায়: তারিখ, ভ্যান, চালক, নির্ধারিত টাকা, জমা, বাকি, পদ্ধতি।
- মাসিক রিপোর্ট, CSV, প্রিন্ট, ব্যাকআপ ও আমদানি।
- একই ডিভাইসে অফলাইনে কাজের জন্য PWA/service worker।

GitHub Pages-এ প্রকাশ:
1. ZIP ফাইলটি কম্পিউটারে Extract করুন।
2. GitHub-এ নতুন repository খুলুন (যেমন cci-pakhi-van)।
3. ফোল্ডারের index.html, manifest.json, sw.js সরাসরি repository-র মূল স্তরে upload করুন।
4. Settings > Pages > Deploy from a branch > main > /(root) > Save।
5. প্রকাশিত URL ফোনে Chrome দিয়ে খুলুন; প্রথমবার অনলাইনে খুলুন, তারপর Install app/Add to Home screen।
6. অফলাইন ক্যাশে চালু করতে প্রথমবার ইন্টারনেটসহ অ্যাপ খুলে রাখুন।

গুরুত্বপূর্ণ সীমাবদ্ধতা:
এটি এখন স্থানীয়-তথ্যভিত্তিক প্রাথমিক সংস্করণ। চালকের ছবি ছোট (সর্বোচ্চ প্রায় 1.2MB) রাখুন। তথ্য ও ছবি এই ডিভাইসের browser storage-এ থাকে; অন্য ডিভাইসে স্বয়ংক্রিয়ভাবে sync হয় না। বহু ডিভাইসে একই তথ্য ও ছবি সিঙ্ক করার জন্য পরবর্তী ধাপে নিরাপদ login, online database ও image storage সংযোগ করতে হবে। এই HTML ফাইলটি একা প্রকাশ করলেই cloud sync তৈরি হয় না।
